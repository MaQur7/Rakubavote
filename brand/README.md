# Brand files

The Rakubavote logo, approved by the project lead (D26): a flat rakuba roof on two posts with a
tick inside. Rules: `docs/brand-guidelines.md` and `docs/design-system.md`.
Fonts are in `assets/fonts/` (SIL Open Font License).

All files are written by `python3 tool/brand_assets.py` from one set of numbers. Do not edit them
by hand; change the script.

| File | Use |
|---|---|
| `rakubavote-mark.svg`, `rakubavote-mark-512.png` | Mark, full colour, on light backgrounds |
| `rakubavote-mark-on-dark.svg` | Mark on Ink |
| `rakubavote-mark-one-colour.svg` | Stamps, photocopies |
| `rakubavote-logo.svg` / `.png` | Mark and name, on light |
| `rakubavote-logo-on-dark.svg` / `.png` | Mark and name, on Ink |
| `rakubavote-logo-one-colour.svg` / `.png` | Mark and name, black |
| `rakubavote-app-icon.svg`, `rakubavote-app-icon-512.png` | App icon: mark on a Nile Blue square |

The SVG logos set the name in Atkinson Hyperlegible Bold as live text, so the font must be
installed where they are opened; use the PNG files where it is not.

## Construction

Unit u = 1/30 of the mark. Roof 26u x 4u (corner 1u). Posts 3u x 16u, 3u in from each roof end.
Bay between the posts 14u x 16u. Tick at 45 degrees, arms 1 : 2, stroke 3u with round ends.
Clear space on every side: 4u (the roof height). Colours: roof Thatch Gold, posts Ink, tick Nile
Blue; on dark, roof Light Thatch and the rest Paper.
