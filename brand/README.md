# Brand files

Draft logo files drawn from mockup board F (`docs/mockups/F-brand.png`). The mark is a first
draft; a local designer should refine it, keeping the roof, two posts and ballot box idea.
Rules: `docs/brand-guidelines.md`. Fonts are in `assets/fonts/` (SIL Open Font License).

- `rakubavote-mark.svg` – full colour mark, for light backgrounds
- `rakubavote-mark-one-colour.svg` – thermal receipts, photocopies, stamps
- `rakubavote-app-icon.svg` – app icon (mark on Nile Blue square)
